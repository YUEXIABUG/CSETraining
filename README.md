# 考公速算训练营（资料分析）

基于 **React 19 + Vite + TypeScript + Bootstrap 5** 的公务员考试「资料分析」速算刷题网站，纯前端、无后端依赖。

## 功能

- **四大训练模块**（首页入口，点击即进入对应训练）：
  - 多位加减法：四个三至四位整数加减混合，至多一个减号、至多一个三位数，**答案必须完全准确**
  - 乘法运算：三位整数 × 小于 100% 的一位小数百分比（如 342 × 32.6%）
  - 分数比大小：两个相差 5% 以内的分数，点击 ＞ / ＜ 按钮作答，成绩单以分数形式展示
  - 基期与增长量：现期量 A（至多五位）与增长率 B（100% 以内），同时填写基期量与增长量，分别判分
- **每组题数自由选择**：默认 5 题，支持 1–100 自定义
- **逐题显示**，每题单独计时 + 全组总计时实时展示
- **判卷规则**：加减法须完全准确；其余填空题答案误差在 1% 以内即判对；比大小点击即提交
- **成绩单**：答完一组后显示正确率（基期与增长量分别统计）、总用时、平均每题用时、逐题对错、我的答案、正确答案（含计算过程）与每题用时，支持一键「再来一组」

## 运行

```bash
npm install
npm run dev      # 开发模式，访问 http://localhost:5173
npm run build    # 类型检查 + 生产构建（产物在 dist/）
npm test         # 出题引擎单元测试（vitest）
```

## 目录结构

```
src/
├── meta.ts                    # 训练模块元信息
├── types.ts                   # 题目类型定义
├── utils/
│   ├── generators.ts          # 四类随机出题引擎 + 判卷容差
│   ├── generators.test.ts     # 出题约束单元测试
│   └── display.ts             # 计时 / 算式 / 成绩单展示辅助
├── components/
│   ├── QuestionViews.tsx      # 填空题 / 比大小 / 基期增量答题组件
│   └── ResultCells.tsx        # 成绩单各列渲染（分数形式展示等）
└── pages/
    ├── HomePage.tsx           # 首页：模块入口 + 题数选择
    └── TrainingPage.tsx       # 训练页：计时、答题、成绩单
```

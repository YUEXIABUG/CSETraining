# 考公速算训练营（资料分析）

> 🔗 在线地址：**[https://csetraining.yxbug.ren/](https://csetraining.yxbug.ren/)**

基于 **React 19 + Vite + TypeScript + Bootstrap 5** 的公务员考试「资料分析」速算刷题网站。纯前端、无后端依赖、无需数据库，所有题目由内置出题引擎随机生成，克隆即可部署。**全程不联网，所有数据（含历次成绩）仅保存在本机浏览器中。**

Bug 反馈：[CSETraining速算网站](https://yxbug.ren/2026/08/23/CSETraining%E9%80%9F%E7%AE%97%E7%BD%91%E7%AB%99/)

## 功能一览

### 训练模块

| 模块 | 题型说明 | 判分规则 |
| --- | --- | --- |
| 多位加减法 | 四个三至四位整数加减混合，至多一个减号、至多一个三位数 | 答案必须完全准确 |
| 乘法运算 | 三位整数 × 小于 100% 的一位小数百分比（如 342 × 32.6%） | 允许 1% 以内误差 |
| 分数比大小 | 两个分数值均在 **1% ~ 10%** 之间、相差 5% 以内，点选 ＞ / ＜ | 选对即得分 |
| 基期与增长量 | 现期量 A（三至五位整数）+ 增长率（**-15% ~ 70%**），同时求基期量与增长量 | 两项各允许 2% 误差，分别判分 |
| 基期比重 · 选择 | 给现期部分 A、整体 B（B 比 A 大 10%~30%）、部分增长率 r<sub>A</sub>、整体增长率 r<sub>B</sub>（均 ±20% 内一位小数，且两者至少相差 5 个百分点），四选一求基期比重 | 选项为位数统一的百分比（至多两位小数） |
| 比重差 · 选择 | 同上条件，四选一判断比重差的方向与数值（A/C 上升、B/D 下降，两组数值相差 20% 以内） | 方向 + 数值均须正确 |
| 套卷模式 | 固定 34 题：4 加减法 + 4 比大小 + 10 乘法 + 2 基期比重 + 2 比重差 + 12 基期增量（6 道 0-20%、2 道 20-70%、4 道 -15%-0） | 按各题型规则判分，进度条分模块展示 |

### 答题体验

- **自由跳题**：点击进度条上的任意题号即可切换；「上一题」按钮可回看并修改已答题目
- **进度条荧光笔样式**：题号为白底圆圈，已答画上绿色荧光笔「Z」字涂抹、看了没答画红色涂抹（粗笔触、笔画重叠处颜色加深、笔锋略微画出圆圈）、未看保持灰底；≤10 题为单列，>10 题每 5 题一行，套卷模式分模块显示
- **下一题 / 提交**：非最后一题显示「下一题」，最后一题显示「提交」；填空题可留空直接下一题，选择题另有「先不答」按钮
- **交卷保护**：提交时若存在未答题目，会弹窗列出未答题号，可选「返回作答」或「仍要提交」
- **离开确认**：答题过程中点击「返回」会弹窗确认，防止误触丢失进度
- **逐题计时**：每题单独累计用时（跳题来回切换也会正确累计）+ 全组总计时实时展示
- **每组题数自选**：单项训练默认 5 题，支持 1–100 自定义（套卷模式固定 34 题）
- **亮暗主题**：右下角悬浮按钮一键切换，自动记忆偏好

### 成绩单

- 正确率（基期与增长量分别统计）、总用时、平均每题用时
- **左侧题号表**：样式与答题中一致，答对为绿色、答错为红色、未作答为灰色（套卷模式按模块分组），点击题号即可定位到该题的记录卡片
- **「仅看错题」**：一键筛选，答题记录仅保留答错与未作答的题目
- **饼图**：答对 / 答错 / 未作答分布；**折线图**：每题用时趋势（套卷模式另有分模块正确率）
- **套卷模式模块详情**：每个模块带「详情」按钮，点击即可展开该模块的正确率、用时统计与逐题记录，再次点击收起
- 逐题记录卡片：题号、题目、我的答案、正确答案（含计算过程）、对错、用时；未作答明确标注

### 我的成绩（个人成绩统计）

- 每次交卷自动记录一条成绩（模块、题数、对错、用时、套卷分模块统计），保存在**本机浏览器本地存储（localStorage）**，最多保留 500 条
- **总览**：练习组数、累计答题、总正确率
- **正确率趋势折线图**：最近半年的总正确率走势，支持**「日记录 / 周记录 / 月记录」切换**（按所选粒度聚合正确率，总图与分模块图同步切换）；数据点悬浮显示白色圆角框 + 黑色正确率。另附**分模块正确率折线图**（每个练习 ≥2 组的模块单独绘制、颜色区分；套卷模式中各模块的成绩也并入对应单项模块的趋势图，以空心点标注来源）
- **分模块统计**：各模块练习量、正确率、平均每题用时，以及**进步幅度**（最近 3 组对比之前 3 组的正确率差值）
- **练习记录**：最近 30 条明细（时间、模块、对错、正确率、用时），每条可点「详情」展开查看该次试卷的对错 / 未答 / 用时明细，套卷模式另含分模块表现
- **导出 / 导入**：一键导出 JSON 文件，在其他设备或浏览器中导入即可**合并**（按记录 ID 去重，不覆盖已有数据），方便跨设备转移成绩；**首次进入（无记录）时也可直接导入**本地 JSON

### 关于页

- 介绍网站功能与判分规则，并明确承诺：**全程不联网**——无后端、无网络请求、无数据收集，所有数据仅存于本机浏览器

## 使用方法

1. 打开 [https://csetraining.yxbug.ren/](https://csetraining.yxbug.ren/)
2. 首页选择「每组题数」（仅影响单项训练模块），点击任意模块卡片进入练习；或点击「套卷模式」开始整卷测试
3. 逐题作答：
   - 填空题输入答案后点「下一题」（回车键同效），可留空跳过
   - 选择题点选选项后点「下一题」，也可点「先不答」跳过
   - 随时点击进度条题号或「上一题」回看、修改答案
4. 最后一题点「提交」；如有未答题目会弹窗提醒，确认后生成成绩单
5. 成绩单页可查看图表分析与逐题详解（套卷模式可点各模块「详情」按钮查看该模块信息），点「再来一组」生成全新一组题目
6. 每次交卷都会自动记入「我的成绩」（首页入口）：查看总正确率与分模块正确率趋势、分模块统计与进步幅度，点每条记录的「详情」可回看该次试卷明细
7. 换设备 / 换浏览器时，在「我的成绩 → 数据管理」中**导出** JSON 文件，到新环境**导入**即可无缝合并（首次进入、还没有记录时也可直接导入）

## 本地部署

要求：[Node.js](https://nodejs.org/) ≥ 18（含 npm）。

```bash
# 1. 克隆仓库
git clone https://github.com/YUEXIABUG/CSETraining.git
cd CSETraining

# 2. 安装依赖
npm install

# 3. 开发模式（热更新）
npm run dev
# 浏览器访问 http://localhost:5173

# 4. 生产构建（类型检查 + 打包，产物在 dist/）
npm run build

# 5. 本地预览生产构建
npm run preview

# 6. 运行出题引擎与页面流程的单元测试（vitest）
npm test
```

### 部署到服务器 / 静态托管

`npm run build` 生成的 `dist/` 是纯静态文件，放到任意静态服务器即可。Nginx 参考配置（SPA 需将路由回退到 index.html）：

```nginx
server {
    listen 80;
    server_name csetraining.example.com;

    root /var/www/csetraining/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

也可以直接部署到 Vercel / Netlify / GitHub Pages / Cloudflare Pages 等平台（构建命令 `npm run build`，输出目录 `dist`）。

## 技术栈

- React 19 + TypeScript + Vite 6
- Bootstrap 5 + Bootstrap Icons（亮暗主题）
- 图表为手写 SVG（环形饼图 / 用时折线图 / 正确率趋势折线图），无额外图表依赖
- 历次成绩保存在浏览器 localStorage，支持 JSON 导出 / 导入合并，无任何网络请求
- Vitest + Testing Library 单元测试
